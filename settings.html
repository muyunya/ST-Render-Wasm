Render WASM · Rust 渲染引擎 + 基准

内置 Rust 编译的 markdown 引擎（WebAssembly，278 KB，无第三方依赖）。
基准测试会用你当前聊天里真实的消息正文，把渲染开销拆成三份分别计时， 看清到底该优化谁：

  • markdown 解析 —— Rust/WASM vs showdown(JS)
  • HTML 净化 —— DOMPurify（DOM 型，WASM 无法替代）
  • 模板编译求值 —— new Function（JS 引擎，WASM 无法替代）
就绪。


            

                引擎 API 已暴露为 window.STRenderWasm.render(markdown)，
